# 2027 工程实践创新能力大赛 — 智能搬运视觉系统开发计划

## 项目概述

本项目为 **2027年中国大学生工程实践与创新能力大赛（智能+工程创新赛道·智能搬运赛项）** 的视觉处理子系统。

### 硬件平台

| 项目 | 规格 |
|------|------|
| **计算平台** | 树莓派 4B / RK3566 (ARM架构，算力有限) |
| **机械臂** | 升降式伸缩塔吊（运动自由度：X平移 + Z升降 + 夹爪） |
| **比赛日期** | **2026年7月23日** |

### 核心视觉任务

1. **多模态标签识别** — 读取二维码、条码
2. **物料颜色识别** — 红/蓝/绿（LAB 色彩空间精准感知）
3. **圆环几何定位** — 识别放置目标点（圆环）的空间坐标
4. **物理坐标映射** — 像素坐标 → 塔吊 X/Y 物理坐标（mm）

> [!IMPORTANT]
> **算力约束**：树莓派4B/RK3566 均为 ARM 架构，无 NVIDIA GPU。视觉处理全程使用传统 OpenCV 方案，避免神经网络推理的高延迟。

> [!TIP]
> **按需触发架构**：系统采用"状态机按需触发"设计，空闲时不运行视觉管线，彻底避免对 Pi 4B CPU 的持续占用。

## 各模块开发状态

### ✅ 已完成模块

#### 1. `qrcode_barcode/` — 二维码识别

| 项目 | 说明 |
|------|------|
| **功能** | 解码赛场中的二维码，提取任务编码与搬运指令 |
| **核心库** | WeChatQRCode (超分辨率增强) + pyzbar (兜底) |
| **关键技术** | 自适应亮度调节、超分辨率增强、抗模糊解码 |
| **ARM适配** | WeChatQRCode 底层为 C++，ARM 性能优异 |

#### 2. `color_detection/` — 颜色感知（LAB 空间）

> [!NOTE]
> **架构升级说明**：本模块已全面从 HSV 迁移至 **LAB 色彩空间**。LAB 将亮度（L通道）与颜色（A/B通道）数学解耦，从根本上消除了 HSV 在复杂光照下的不稳定性。

| 项目 | 说明 |
|---|---|
| **功能** | 通过 LAB 色彩模型精确提取特定颜色的物料 |
| **核心库** | OpenCV, NumPy |
| **关键技术** | L通道 CLAHE 自适应光照补偿 → A/B通道 inRange 阈值切片 → 形态学滤波 |
| **ARM适配** | 相比原 BGR→LAB→BGR→HSV 链路，计算量骤降约 40% |

#### 3. `shape_detection/` — 圆环拓扑检测

| 项目 | 说明 |
|---|---|
| **功能** | 在灰度自适应二值化图像中，精准定位放置目标"圆环"的像素中心坐标 |
| **核心库** | OpenCV |
| **关键技术** | `RETR_TREE` 父子轮廓拓扑分析 + 圆度公式 $C = \frac{4\pi S}{L^2}$ + NMS去重 |
| **关键决策** | **圆环不依赖颜色**，完全通过几何拓扑（一个外圆包含一个内孔洞）判断，抗光照干扰彻底 |

#### 4. `calibration/` — 相机内参标定

| 项目 | 说明 |
|---|---|
| **功能** | 计算相机焦距、光学中心、畸变系数，提供零开销去畸变 |
| **核心库** | OpenCV (`calibrateCamera`, `initUndistortRectifyMap`) |
| **关键技术** | 张正友棋盘格法（亚像素精度）+ 预计算 remap 映射表（ARM 侧极速查表） |
| **参考文档** | `docs/相机标定开发与测试指南.md` |

#### 5. `utils/` — 基础工具链

| 文件 | 说明 |
|------|------|
| `camera_stream.py` | 多线程摄像头采集，防止主线程阻塞，支持外接 USB 摄像头 |
| `serial_comm.py` | USB CDC JSON 通信协议，自带断线重连与帧完整性校验 |
| `logger.py` | 时间戳日志输出 |
| `timer.py` | FPS 与帧耗时统计 |
