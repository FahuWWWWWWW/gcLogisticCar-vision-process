# 2027 工程实践创新能力大赛 — 智能搬运视觉系统开发计划

## 项目概述

本项目为 **2027年中国大学生工程实践与创新能力大赛（智能+工程创新赛道·智能搬运赛项）** 的视觉处理子系统。

### 硬件平台

| 项目 | 规格 |
|------|------|
| **计算平台** | 树莓派 4B / RK3566 (ARM架构，算力有限) |
| **机械臂** | 升降式伸缩塔吊（运动自由度：X平移 + Z升降 + 夹爪） |
| **比赛日期** | **2026年7月23日**（距今 30 天） |

### 核心视觉任务

1. **多模态标签识别** — 读取二维码、条码、图形、数字、文字
2. **复杂物料特征识别** — 颜色（红/黄/蓝/绿/黑/浅蓝）、形状（圆柱/方形/三角/球/锥/组合体）、位置
3. **赛场环境感知** — 识别障碍物（黑色圆柱 φ50×100mm）

> [!IMPORTANT]
> **算力约束**：树莓派4B/RK3566 均为 ARM 架构，无 NVIDIA GPU。模型推理必须使用 **ONNX Runtime / NCNN / RKNN** 而非 TensorRT。YOLO 模型必须选用 **nano 级别**，且优先考虑传统 OpenCV 方案能解决的任务。

> [!TIP]
> **塔吊简化**：升降式伸缩塔吊的运动学远比多关节机械臂简单（本质是 1D轨道平移 + Z轴升降），位姿估计模块只需提供目标在轨道方向的物理坐标(X)和高度(Z)，完全不需要 Y 轴或复杂的姿态角计算。

## 各模块功能定义与技术选型

### 1. `qrcode_barcode/` — 二维码 & 条码识别

| 项目 | 说明 |
|------|------|
| **功能** | 解码赛场中的二维码（80×80mm）和条形码，提取任务编码与搬运指令 |
| **核心库** | `pyzbar`（解码）、`OpenCV`（图像预处理与定位） |
| **关键技术** | 二值化增强、透视矫正、ROI裁剪、抗模糊解码 |
| **ARM适配** | `pyzbar` 底层为C库（libzbar），在ARM上性能良好，无需额外优化 |
| **预期文件** | `qr_decoder.py`, `barcode_decoder.py`, `preprocessor.py` |

---

### 2. `color_detection/` — 颜色检测

| 项目 | 说明 |
|------|------|
| **功能** | 识别物料颜色（红、黄、蓝、绿、黑、浅蓝），含色差抗干扰 |
| **核心库** | `OpenCV`（HSV颜色空间分割）— 纯CPU即可高效运行 |
| **关键技术** | BGR→HSV转换、`cv2.inRange` 阈值分割、形态学去噪、自适应光照补偿 |
| **ARM适配** | OpenCV HSV操作为纯CPU计算，树莓派上可达 30+ FPS |
| **预期文件** | `color_classifier.py`, `hsv_tuner.py`, `color_config.yaml` |

> [!IMPORTANT]
> 建议开发一个可视化的HSV调参工具（`hsv_tuner.py`），使用 trackbar 实时调节阈值，方便现场快速校准。

---

### 3. `shape_detection/` — 圆环形状识别

| 项目 | 说明 |
|---|---|
| **功能** | 在提取出的色块掩码中，利用轮廓的拓扑结构找出“圆环”物料，提取其中心坐标 |
| **核心库** | `OpenCV` |
| **关键技术** | 1. **RETR_TREE 轮廓层级分析**：圆环在二值图中必然表现为一个“外轮廓”包含一个“内轮廓（孔洞）”，这是极强的拓扑特征。<br>2. **圆度公式(Circularity)**：$C = \frac{4\pi S}{L^2}$，过滤掉非圆形噪块。 |
| **ARM适配** | 传统纯几何计算，单帧耗时极低 |
| **预期文件** | `ring_detector.py`, `contour_analyzer.py` |

---

### 4. `ocr_recognition/` — OCR 文字/数字识别

| 项目 | 说明 |
|------|------|
| **功能** | 识别物料表面的文字、数字等多模态标签信息 |
| **核心库** | `PaddleOCR-Lite` 或 `EasyOCR` |
| **关键技术** | 文本检测 + 文本识别、小字体增强 |
| **ARM适配** | PaddleOCR 提供 ARM 优化的 Lite 版本；EasyOCR 可用 ONNX 后端 |
| **预期文件** | `text_recognizer.py`, `digit_recognizer.py` |

---

### 5. `object_detection/` — YOLO 目标检测（含障碍物）

| 项目 | 说明 |
|------|------|
| **功能** | 统一检测物料、标签、黑色障碍物等目标 |
| **核心库** | `ultralytics`（YOLOv8n / YOLOv5n） |
| **关键技术** | 自定义数据集标注、模型训练、**ONNX/NCNN/RKNN 导出与推理** |
| **ARM适配** | 见下表 |
| **预期文件** | `yolo_detector.py`, `train.py`, `export_model.py` |

**ARM 推理方案选择**：

| 平台 | 推荐方案 | 预期性能 (YOLOv8n, 640×640) |
|------|----------|---------------------------|
| 树莓派 4B | NCNN / ONNX Runtime | ~5-8 FPS |
| RK3566 | RKNN (NPU加速) | ~15-25 FPS |

> [!WARNING]
> 树莓派4B 跑 YOLO 帧率偏低。建议策略：**OpenCV 传统方案为主（颜色+形状），YOLO 仅在复杂场景下触发**，避免每帧都跑模型推理。若 RK3566 可用，优先使用其 NPU 加速。

---

### 6. `pose_estimation/` — XZ 坐标定位

| 项目 | 说明 |
|------|------|
| **功能** | 计算目标物体在轨道上的物理位置(X)和高度(Z)，输出给塔吊控制系统 |
| **核心库** | `OpenCV`（像素→世界坐标映射） |
| **关键技术** | 单目定位：标定后使用已知物体尺寸反算距离；或固定高度俯拍+透视变换直接映射 |
| **ARM适配** | 纯数学计算，无性能瓶颈 |
| **预期文件** | `coordinate_transform.py`, `height_estimator.py` |

> [!TIP]
> 塔吊的运动空间是笛卡尔坐标系，如果相机固定在塔吊顶部俯拍，可以使用**透视变换 + 比例尺**直接将像素坐标映射为物理坐标，无需复杂的 solvePnP。

---

### 7. `calibration/` — 相机标定 & 手眼标定

| 项目 | 说明 |
|------|------|
| **功能** | 相机内参标定（去畸变）、像素坐标→塔吊坐标映射 |
| **核心库** | `OpenCV`（`calibrateCamera`, `getPerspectiveTransform`） |
| **关键技术** | 棋盘格标定、透视变换矩阵、四点标定法 |
| **预期文件** | `camera_calibrator.py`, `perspective_calibrator.py`, `calibration_data.yaml` |

---
