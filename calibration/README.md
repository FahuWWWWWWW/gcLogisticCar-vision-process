# 相机标定系统 (Calibration)

本目录包含用于将“扭曲的像素坐标”转化为“精准的物理坐标”的两大核心工具。
必须**严格按照 1 -> 2 的顺序**执行，绝对不可颠倒！

## 1. 内参去畸变标定 (`camera_calibrator.py`)

**目的**：计算相机透镜的物理曲率，消除画面边缘的“鱼眼”扭曲。
**依赖**：打印一张标准 A4 棋盘格（内角点 9列×6行，方格边长 20mm）。

**操作步骤**：
1. 运行 `python camera_calibrator.py`
2. 拿着棋盘格在镜头前不同角落、不同倾斜角度晃动（注意不要全挤在画面正中间）。
3. 看到绿点提示后，按 `s` 键抓拍 15~20 张。
4. 按 `c` 键开始计算。
5. **验收标准**：输出的 RMS 误差最好在 0.5 像素以下。
**产出**：永久保存为 `../config/camera_params.npz`。

---

## 2. 外参透视坐标映射 (`perspective_calibrator.py`)

**目的**：计算透视变换矩阵 (M)，实现像素坐标 `(u, v)` 到塔吊底盘物理坐标 `(X, Y) mm` 的直接转换。
**超级警告**：
- 必须先成功完成第 1 步！
- **进行此步前，摄像头必须按照比赛实际高度和俯视角度固定死，以后绝不能再碰！**（碰歪了就得重做这一步）。

**操作步骤**：
1. 在地上（或塔吊作业平面）放一张 A4 纸（标准尺寸 297mm × 210mm）。
2. 运行 `python perspective_calibrator.py`。
3. 确保画面清晰无畸变后，按 `空格键` 冻结画面。
4. 用鼠标**严格按【左上 -> 右上 -> 右下 -> 左下】的顺序**，精准点击四个角点。
5. 回车，并在终端确认物理尺寸（A4 纸直接按回车即可）。
**产出**：永久保存为 `../config/perspective_params.npz`。
